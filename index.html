Frequently Asked Questions

Is my data safe?

Absolutely! All processing happens locally in your browser. Your photos never get uploaded to any server.

What file formats are supported?

We support JPG, JPEG, PNG, GIF, and many other image formats. Video support (MP4, MOV) is coming soon.

How long does processing take?

Processing time depends on the number of files. Most users process their entire library in a few minutes.

Do I need to install anything?

No! This is a web-based tool that works directly in your browser. No installation required.

Is this really free?

Yes! This is a free, open-source alternative to commercial metadata fixers.
